# Changelog

## 1.0.0

First release on the VS Code Marketplace.

- Opens every `.pdf` in VS Code with a drawing toolbar. Built on PDF.js 6.2.108.
- Pen: freehand ink in 6 colours, size 1 to 20. Pen, touch-screen stylus and mouse all draw, and you can switch between them at any time.
- Highlighter: translucent marker in 5 colours, size 6 to 40. It checks the page under each highlight and blends so text stays readable, on light pages and on dark slides.
- Eraser: Whole stroke or Partial mode, size 6 to 80. One swipe is one undo step, and Undo brings back everything it erased.
- Laser pointer for presenting: glowing strokes that fade 1 to 15 seconds after you stop. Never saved into the file.
- Undo and Redo (Ctrl+Z, Ctrl+Y) for drawing and erasing. Clear this page or the whole file.
- Ctrl+S saves the ink into the PDF as standard ink annotations, so other PDF readers show it too.
- Find in the document, page thumbnails, page navigation and zoom (page width, page fit, 50% to 400%).
